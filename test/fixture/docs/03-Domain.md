# Domain

| Term | Identifier | Meaning |
|---|---|---|
| greeting | `hello` | the line printed with no verb or with `hello` |
| farewell | `bye` | the line printed with the verb `bye` |
| language | `--lang` | `en` (default) or `pt`; chooses the words |
| shout | `--shout` | the line in upper case |
